# AGENTS.md

Instructions for any coding agent working in this repository.

1. **Read [`principles.md`](principles.md) first and follow it.** It holds all generic working instructions (how to plan, verify, test, use git, handle secrets, and communicate). Do not expect them to be repeated here, and do not add generic rules to this file; add them to `principles.md`.
2. **Read [`docs/giml-spec.md`](docs/giml-spec.md)** for what this project is, its hard rules, milestones and acceptance criteria.
3. **Read [`CLAUDE.md`](CLAUDE.md)** for the current project state: status, working build and test commands, decisions and gotchas. Ignore its `@principles.md` import line; you have already read that file in step 1.

If any of these conflict, stop and ask before proceeding.
